DATA VISUALIZATION / 2025

Inequality in Smoking Prevalence

Smoking rates aren't one number. The differences tell the story.

A public-health analysis exploring how smoking prevalence changes across place, education, age, race, and sex. Rather than reduce the problem to one national average, I wanted people to be able to see the disparities.

I cleaned and combined public datasets, used SQL and Python to examine trends, and helped create interactive visualizations that made comparisons easier to explore.

AI + PRODUCT / 2026

BalanceBasket

Grocery planning should understand your pantry, not start from scratch.

A budget-aware grocery planner that brings together lists, pantry tracking, meal ideas, and AI-assisted recommendations. The challenge wasn't just generating an answer. It was giving the assistant enough context to make the answer useful.

I led backend and AI assistant work, creating FastAPI endpoints and database workflows that pass cart items, pantry contents, budgets, and dietary preferences into the recommendation experience.

AI EVALUATION / 2026

LLM Evaluation Harness

A convincing answer isn't the same as a correct one.

A repeatable way to compare language models across the same prompts. I wanted to move past choosing models based on a handful of impressive examples and look at how reliably they perform.

I developed standardized prompt tests, automated scoring workflows, and dashboard reporting focused on pass rate, refusal accuracy, hallucination rate, and consistency.

PYTHON · OLLAMA · MODEL EVALUATION · POWER BI

SEMANTIC SEARCH / 2026

Search Quality Evaluation

Finding a relevant source is the first step toward a trustworthy answer.

A semantic search and retrieval project built around embeddings, vector similarity, and source-grounded responses. The interesting question was not only whether a system could return text, but whether that text was actually relevant.

I worked with document preprocessing, embedding-based retrieval, similarity scoring, and evaluation planning to identify failure modes and assess search quality.

PYTHON · MONGODB · OLLAMA · RAG
